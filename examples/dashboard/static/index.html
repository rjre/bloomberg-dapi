How this is priced

price = F·N(d1) − K·N(d2) (call, undiscounted) price = K·N(−d2) − F·N(−d1) (put) d1 = [ln(F/K) + ½σ²T] / (σ√T), d2 = d1 − σ√T
  • No Bloomberg tag prices this strike directly. The smile is recovered from each tenor's ATM vol + 25D/10D risk-reversal & butterfly quotes: vol(25D call)=ATM+BF25+½RR25, vol(25D put)=ATM+BF25−½RR25 (and likewise at 10D).
  • Strikes are recovered by inverting the forward-delta formula (d1=N⁻¹(δ) for a call, N⁻¹(1−δ) for a put; K=F·exp(−d1·σ√T+½σ²T)). Several pairs (JPY crosses among them) actually quote off premium-adjusted delta instead in practice, a different (and not exposed here) strike for the same quoted delta — nothing here confirms which convention any given pair uses, so this is a known simplification, not a claim that plain forward delta is always correct.
  • ATM strike ≈ forward. The true delta-neutral-straddle correction is a few pips to a percent at most for these tenors.
  • Domestic (quote-currency) discounting is dropped. The quoted forward already embeds the rate differential; only the discount factor itself (worth basis points here) is dropped.
  • "Premium %" is against the call currency: a put on the base currency calls the quote currency (premium ÷ strike); a call on the base currency calls the base currency itself (premium ÷ spot).
  • This is a modelled fair value, not a dealer's quote: it carries none of a real market-maker's skew, inventory, or bid/ask.

How this is priced

Unlike the FX Option tab, there's no model here at all: SPX/SPXW options are exchange-listed (Cboe), and Bloomberg already carries live bid/ask/last plus its own computed delta/gamma/vega/rho/theta directly on each specific contract. Reading Bloomberg's own analytics for the real listed contract is strictly more faithful than re-deriving a vol surface from moneyness-bucketed fields and running a second, independent pricer on top of it, so that's what this page does.

  • Strike snapping. SPX strikes are listed at fixed increments (25pts near the money for near-dated expiries, confirmed live), not at every number — the strike you type is snapped to the nearest one that's actually listed (shown above if it differs from what you typed).
  • The ticker is "SPXW US {expiry} {C|P}{strike} Index". "SPXW" resolved identical data to "SPX" for every near-dated expiry checked live, so it's used unconditionally rather than guessing which root a given expiry needs.
  • Overrides are a linear (delta/vega) scenario, not a reprice — see the note above the stats. There's deliberately no independent Black-Scholes model here to rerun at a hypothetical spot/vol (that would be a second, unverified pricer sitting next to Bloomberg's own), and deliberately no gamma term either — tried it live and a modest spot override on a short-dated, high-gamma contract sent the quadratic term past what the option could actually be worth. A plain linear scenario off the live greeks is the honest alternative to either.
